# 100 Days of Cloud

This repository contains the documentation of my **100 Days of Cloud** learning journey.

The purpose of this repository is to record daily, hands-on cloud practice and learning activities in a structured and easy-to-follow way.

## What I Do Daily

Each day of the challenge focuses on a specific cloud task or concept. This may include:
- Creating or configuring cloud resources
- Exploring cloud services and features
- Practicing networking, security, or optimization tasks
- Making small changes to existing resources to understand real-world cloud workflows

Every task is documented with:
- A brief description of the objective
- The cloud service involved
- Key observations or lessons learned from the exercise

## Scope of the Journey

The challenge covers:
- Amazon Web Services (AWS)
- Microsoft Azure

The learning approach is guided by hands-on labs and scenarios, primarily using the KodeKloud platform.

## Repository Organization

The repository is organized by:
- Cloud provider (AWS and Azure)
- Individual days within the 100-day challenge

Each day represents a focused learning step rather than a large project, emphasizing consistency and gradual skill development.

## Learning Approach

This repository emphasizes:
- Practical, hands-on learning
- Incremental progress through daily practice
- Understanding cloud concepts through real usage
- Building strong foundational cloud skills over time

## Intended Audience

This repository is intended for:
- Individuals learning cloud computing
- Developers and engineers building cloud fundamentals
- Anyone interested in structured, daily cloud practice

This repository serves as a learning log and reference for cloud concepts explored throughout the 100-day journey.
